二、目录各自是什么
01_现有项目原样保存：现有Demo和三维源码的原样副本，附已构建网页、必要图片/说明/许可证与早期A至D演示视频。不是新的后台或现场设备系统。原始源码校验清单在“验证记录”目录。
02_规则原型分离学习版：把原来一个HTML中的CSS和JavaScript抽出为styles.css和app.js，仅调整本地三维导航链接。index.html可直接打开；功能与原样规则版一致。
03_数据与状态机练习：本次新增的教学代码，独立于原程序。training-engine.mjs使用纯函数演示字段校验、旧建议版本失效、人工复原确认、冷却、区域映射和自愿资源匹配；原系统尚未直接调用这些文件。
04_中文注释源码：保留原逻辑，补充中文职责/输入/结果/注意事项。规则原型/index.html对应注释app.js；三维展示/是注释后的构建源；此目录根部“三维空间交互展示.html”是已经构建并核对的运行网页。视频播放器/同步预览.js是从旧播放器抽出的逻辑参考，不是单独可播放的页面。
assets：说明书图片资源。保持与两份说明书HTML在同一目录，避免图片丢失。
本人记录模板：空白记录模板，需本人真实执行后填写，未预填调研或测试成绩。
验证记录：本次实际运行检查与源文件哈希，不代表图书馆现场、识别精度或声学验收。

三、修改什么文件
修改规则/资源入口：先用02目录的app.js。样式改styles.css；结构或按钮文字改index.html。HTML id和脚本getElementById之间必须一致。
修改楼层馆藏参照：library-layout.js中的FLOOR_INFO。相对分区有公开导览参照，尺寸、柱梁、家具数量和一楼平面仍需现场核对。
修改五层候选方案：floor-pilots.js中的PILOT_INFO与moving记录。原馆藏和结构不应随试点移动；五楼moving为空，只演示静音席位信息。
修改外观和檐角：architecture.js。这里按公式组合概念几何，屋檐不是工程受力计算。
修改湖畔平台/入口标识：library-environment.js。标识字样、尺度和位置仍为示意。
修改按钮、场景状态、相机、动画：scene.js；viewer-template.html管理页面布局。scene.js目前同时包含多项职责，先改小范围，核对关联状态。
修改构建：build.cjs与package.json；后者固定three 0.180.0、esbuild 0.25.10。

四、重新构建三维页面
直接看已构建网页无需安装Node。只有修改源文件后重建才需要Node.js和依赖。
请另复制一份学习目录，打开包含package.json的源码文件夹，在文件管理器地址栏输入powershell并回车，然后运行：
  npm install
  npm run build
首次安装依赖需要网络。输出会覆盖源码文件夹上一级的“三维空间交互展示.html”，请先保存原网页与自己的改动。
原样版源码目录：01_现有项目原样保存/06_三维空间设计/模型源码
中文注释版源码目录：04_中文注释源码/三维展示
不要直接打开viewer-template.html当成最终展示页，它中的打包占位符必须由build.cjs替换。
GLB是导出快照：在Blender中改GLB不会自动改回网页。要改网页需修改JavaScript参数并构建；模型/截图/PDF/MP4也不会随构建自动更新。

五、运行教学练习（Node 20或更新版本）
在“03_数据与状态机练习”目录打开PowerShell：
  node demo.mjs
  node --test tests/engine.test.mjs
这部分不依赖Three.js，不需要npm install。demo按顺序展示申请、批准、恢复、冷却阻止、重新申请；31项测试检查具体边界和状态变化。
示例输入中“05_非法字段_应拒绝.json”故意带额外字段，应当被拒绝。所有人数、主题、预约和置信度都是演示输入，不要导入真实姓名、学号、图像或门禁明细。
教学版加入了version、manualReview、staffConfirmed等概念，是学习未来工程可靠性的练习，不能在答辩中说原版已经实现了这些后台能力。

六、最重要的实际边界
规则Demo与五层模型是两个独立HTML程序，当前不共享状态，也没有共同后台。互相链接只是导航。不能把B区硬对应为三楼。
当前没有真实视觉模型、大语言模型、馆内API、实时预约数据、家具机器人或IoT控制。已有渲染和动画可以运行；它们不是物理碰撞、声学、通行或承重计算。
三维“模拟无人5分钟恢复”与“推进模拟冷却10分钟”直接改演示状态，不是连续传感器计时。读者退出资源会话也不会自动结束空间使用。
原视频仍是无配音字幕版；本机录音选择功能仅同步预览，不会导出带声音的MP4。本人录音应另外剪辑合成并检查音轨。
移动有噪声风险，尤其是轮子、刹车、接缝、碰撞、脚步和中庭传播。首期先考虑固定设施和信息服务，不适合时取消家具移动。测试方法见PDF第12章。
