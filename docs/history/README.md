## 如何理解这些证据

历史备份只能说明保留下来的文件内容，不能据此补造已经丢失的中间版本或开发日期。部分旧资料有后续已修订的方案和布局，仅供回顾。核对记录按当时范围保留，不把纯逻辑或几何检查写成真实浏览器、真实占用识别或用户试点成果。

## 当前产品边界

主线是智能选座和学习资源联动，三维辅助定位。登记与状态目前在本机保存；正式服务还需要馆方政策、真实座号、共享后台、身份和冲突处理。馆舍模型依据实地说明及参考照片制作，未达到测绘精度。语音使用可选的预训练ASR，条件抽取与推荐采用可解释规则。
