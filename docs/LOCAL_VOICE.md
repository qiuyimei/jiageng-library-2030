# 本机语音运行与维护

主页面可使用 Vosk 公开预训练中文模型将录音转为文字，再用本地关键词、否定判断等规则提取选座条件。用户核对文字并确认条件后才生成候选；它没有接入大语言模型，不会自动预约或登记，也不提供全馆共享后台。

## 准备与启动

先完整解压仓库。普通文字输入和已构建的网页不需要 Python。可选本机语音建议使用已验证的 Windows 64 位 Python 3.12，并在同一个 Python 环境中安装依赖、准备模型和启动服务。在仓库根目录运行：

```powershell
py -3.12 -m pip install -r src/requirements-voice.txt
py -3.12 src/prepare_voice.py
.\scripts\start-local-voice.cmd
```

启动器优先使用环境变量 `JIAGENG_PYTHON` 指定的解释器，否则尝试 `py -3.12`，再尝试 `python`。例如使用虚拟环境：

```powershell
$env:JIAGENG_PYTHON = (Resolve-Path .venv/Scripts/python.exe).Path
.\scripts\start-local-voice.cmd
```

也可用选定的解释器直接运行 `scripts/start-local-voice.py`。启动器按自身位置寻找仓库，不依赖终端当前目录；成功监听后才尝试打开浏览器。仓库不附 Python、Vosk 二进制依赖或模型权重，其他系统与 Python 版本需按 Vosk 的支持情况自行安装。

如果 `Demo/嘉庚知座.html` 尚不存在，先在仓库根目录运行 `npm ci` 和 `npm run build`。维护源码时可执行 `powershell -File scripts/check-and-build.ps1`：它先运行核心检查，成功后构建 4 个 HTML；检查失败不会继续构建，也不会改动照片、音频或模型文件。

直接启动服务的等价入口是：

```powershell
py -3.12 src/voice_server.py --root .
```

通过终端给出的 `http://127.0.0.1:8766/Demo/...` 地址进入主页面。需要自选端口或退出时限时，可直接为服务指定 `--port`、`--idle`（秒）。8766 端口被占用时，启动器报错退出，不会自动打开已有服务。健康接口表明服务可响应，不代表模型已完成加载或真实录音识别已验收。

## 录音、核对与停止

1. 点击“开始说话”，由使用者决定是否允许浏览器访问麦克风；说完点击“结束录音”。
2. 核对转写文字，必要时修改，再点击“解析这句话”。
3. 核对条件，点击“确认条件并推荐”。安静阅览区可直接输入文字。

本机服务只绑定回环地址。页面将录音转换为 16kHz、单声道、16 位 PCM WAV；接口只接受 0.1 至 30 秒的录音。音频在内存中转写，不上传、不写入录音文件，服务日志不记录转写文字。当前代码仍需使用者核对识别结果，没有真实馆内识别率结论。

可关闭终端、按 Ctrl+C，或使用页面中的“结束本地语音服务”；默认 10 分钟没有有效访问后退出。程序不设置开机启动或常驻后台任务。

直接打开的 `file:` 网页、`127.0.0.1` 与 `localhost` 属于不同存储来源，本机登记不会自动互通。浏览器自带的 SpeechRecognition 路线可能使用在线服务，其接口与网络可用性不能保证；本机 Vosk 与文字输入是另外的使用方式。

## 模型来源与校验记录

Vosk API 版本固定在 `src/requirements-voice.txt`，中文模型为 `vosk-model-small-cn-0.22`。来源、官方许可标识、模型归档与 14 个文件的 SHA-256 见 [模型来源与校验](../src/models/vosk-model-manifest.json)。这些记录用于核对公开第三方模型，不表示本项目训练了语音模型。

`prepare_voice.py` 从记录的官方地址下载并解压到 `src/`，同时计算此次下载的 SHA-256；它目前不会自动与固定清单比对，也不执行签名验证。需要复核时，应自行将实际归档及模型文件哈希与清单比较。

API 和模型的许可信息需与第三方官方材料一起阅读。重新分发模型或二进制依赖时，应保留适用许可全文、NOTICE 及依赖自带的许可和元数据；仓库中的来源说明不能替代这些文件。个人录音、人物素材、原始研究照片和模型权重不随本次源码增量上传。
